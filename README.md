# NareshIT Placement AI

NareshIT Placement AI is an intelligent, integrated platform designed to help students build ATS-friendly resumes, analyze their resumes against job descriptions, and discover relevant job opportunities on an interactive geographic map.

## Project Status

**IMPLEMENTED**
- AI Resume Maker (Form to ATS-friendly resume via Gemini)
- Resume Parsing & ATS Analysis (PyMuPDF + Gemini)
- AI Job Matching & Cover Letter Generation (Gemini)
- Location-based Job Search Map (MapLibre + OpenFreeMap + Photon Geocoding)
- Job Scraping (python-jobspy for LinkedIn, Indeed, Glassdoor)
- Exclusive Jobs Admin Portal (SQLAlchemy CRUD)
- Dark Mode / Theme Toggle
- PostgreSQL Support & Render Deployment Configurations

**PLANNED / NOT IMPLEMENTED**
- Direct Application System (External applications only)
- Student Application History Tracking
- User Authentication (Login/Signup)
